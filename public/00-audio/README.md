# KidMotion — Audio Drop / ACTIVE EPISODE STAGING

This folder is the Remotion voice staging area for ONE active episode at a time.

## HARD RULE — NEVER MIX EPISODES
Episode voice files reuse names such as `Voice 01.mp3`, `Voice 04.mp3`, etc.

Before loading a different episode:
1. archive the current episode audio if needed
2. remove the previous episode voice files from this staging folder
3. place only the new active episode's voice files here
4. verify all filenames against that episode's `ALL_VOICE_TEXTS.md` / data before rendering

Voice does NOT control video duration.
A roughly 1-minute total narration can be used inside a 5+ minute workout because the 20-second hold scenes continue silently after each short cue.

## Exercise audio rule
Typical exercise:
- first ~3–4 seconds: short spoken cue
- remaining time until second 20: silence
- pose image, timer and progress bar continue for the complete 20 seconds

Do NOT create filler narration for the waiting time.
Do NOT stretch a short cue.
Do NOT shorten the exercise to the audio length.

## If the user provides ONE master audio file
Do NOT stretch it across the full video.
Do NOT shorten the video to match it.

Antigravity / Codex must split or position the spoken sections according to `ALL_VOICE_TEXTS.md` and the scene timeline.
The final timeline still contains the full silent waiting periods.

## No subtitles
Never convert the voice into automatic subtitles or word-for-word captions.
Intentional Remotion scene UI is separate from subtitles.
