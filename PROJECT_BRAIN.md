# KidMotion — Project Brain

Canonical current rules for KidMotion.

## Current focus
English SPORT / FITNESS long-form videos using static Google Flow images and Remotion.

## Character
KidMotion has a boy and girl overall, but one episode uses exactly ONE main character. The chosen character stays the same for the whole video. No switching and no second visible person.

## Every visible section uses the character image
Current standard:
- Cover `Bild 00` = thumbnail only, not in MP4
- Intro `Bild 01`
- Safety `Bild 02`
- LET'S BEGIN `Bild 03`
- exercises = matching image
- Rest = reuse NEXT exercise image as full-screen background
- Outro = matching image

Do not use blank/plain screens for Safety, Rest or Outro.

## No subtitles
Never add automatic captions, word-for-word voice text, transcript bars, karaoke text or subtitle boxes.

Allowed Remotion scene UI only:
- Intro graphics
- SAFETY FIRST
- LET'S BEGIN
- exercise title bottom-left
- short instruction upper-right
- timer top-left
- progress bar bottom
- REST / NEXT
- GREAT JOB

## Google Flow
Except for Cover, source images are clean. Generate character + pose + environment only. Do not bake exercise text, instructions, subtitles, timer, progress or other UI into normal images.

Use the approved episode character reference. Keep face, hair, age appearance, proportions, outfit, world and 3D style consistent.

Generate one image at a time and rename it immediately before continuing.

## Exercise timing
Current format uses static hold poses. Every exercise lasts exactly 20 seconds. Typical Rest = 5 seconds. Timer reaches 0 and progress reaches 100%.

## Voice
Voice only when useful. A short voice cue does not shorten a 20-second scene. The remaining hold time can stay silent. Audio length never controls video length.

## Remotion
Remotion adds all intentional video UI over the character images and controls the full timeline.

## Publishing
Exactly one cross-platform English caption per episode with exactly 5 hashtags including `#KidMotion`.
