# KidMotion Project Brain

Source of truth: `GEHIRN.md`.

KidMotion V2 nutzt Google Flow für die komplette sichtbare Bildgestaltung inklusive **aller Texte**. Remotion ist kein Designsystem mehr; es setzt die statischen Bilder zeitlich zusammen, spielt Audio und legt ausschließlich den Countdown-Timer über Exercise/Rest.

Kein Remotion-Progress-Bar, Intro-Text, Safety-Text, LET'S BEGIN, Exercise title/instruction, REST/NEXT oder Outro-Text.

Bild 01 = Character/World Reference. Bild 04 = Exercise UI Reference. Finalbilder = `00-bildprompts/images/`. Export = Video + Upload-Titel/Beschreibung.
