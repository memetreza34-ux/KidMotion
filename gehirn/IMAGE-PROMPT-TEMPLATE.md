# KidMotion — Image Prompt Template

## Current image rule
Every actual video section uses an image with the same chosen episode character.

Standard:
- `Bild 00.png` Cover — thumbnail only
- `Bild 01.png` Intro
- `Bild 02.png` Safety
- `Bild 03.png` LET'S BEGIN
- exercise scenes = matching `Bild XX.png`
- Outro = final matching image

Rest reuses the NEXT exercise image and does not use a blank card.

## Character continuity
One episode uses exactly one main character.
Create `Bild 01.png`, approve it, then use `Bild 01` as the primary visual reference for every later generated image.

Keep the same face, hair, age appearance, proportions, outfit, world and 3D style.

## HARD RULE — exercise title + instruction are generated by Google Flow
For every exercise image, Google Flow creates the final visual information directly inside the image:
- exercise title at BOTTOM-LEFT
- short instruction at TOP-RIGHT inside the KidMotion white cloud/info bubble

Remotion must not recreate or duplicate these two elements.

The exercise image must NOT contain:
- subtitles
- transcript bars
- timer
- progress bar
- duplicate title
- duplicate instruction

Keep TOP-LEFT free for the Remotion timer and the bottom edge free for the Remotion progress bar.

## Title style
- bold white KidMotion athletic lettering
- dark navy outline/shadow
- compact and readable
- bottom-left
- not oversized

## Instruction cloud style
- top-right
- white playful cloud/info bubble
- turquoise/aqua outline
- subtle shadow
- dark navy bold rounded text
- maximum 2–3 lines
- never cover the character's face or important joints

## Numbering
Every prompt begins with:
```text
IMAGE NUMBER: Bild XX
SCENE: SCENE XX — NAME
FINAL FILE NAME: Bild XX.png
```

and ends with:
```text
After generation immediately rename to: Bild XX.png
```

## Google Flow workflow
`PROMPT LESEN → GENAU EIN BILD ERZEUGEN → SOFORT UMBENENNEN → ERST DANN NÄCHSTES BILD`

Never batch episode images.

## Standard exercise prompt
```text
IMAGE NUMBER: Bild XX
SCENE: SCENE XX — [POSE NAME]
FINAL FILE NAME: Bild XX.png

Use approved Bild 01 as the PRIMARY visual reference.
Show exactly the same KidMotion episode character, outfit and world.

POSE:
[short exact body-position description]
Full body clearly visible. Static hold pose.

BOTTOM-LEFT TITLE:
[POSE NAME]

TOP-RIGHT CLOUD:
[SHORT INSTRUCTION]

Create the title and instruction directly inside this image in the approved KidMotion style.
Keep TOP-LEFT clear for the Remotion timer.
Keep the bottom edge clear for the Remotion progress bar.

NO subtitles.
NO transcript bars.
NO timer.
NO progress bar.
NO second person.

After generation immediately rename to: Bild XX.png
```

## Intro / Safety / Start / Outro
These scenes also show the same character.
- Intro leaves useful space for the fixed branded opening information.
- Safety leaves space for the Safety panel.
- LET'S BEGIN leaves space for the start graphic.
- Outro leaves space for GREAT JOB.

## Remotion adds
For exercises ONLY:
- 20-second timer top-left
- progress bar bottom
- scene timing
- optional audio placement

Remotion does NOT add exercise title or instruction.

For non-exercise sections Remotion may add:
- fixed Intro information
- Safety panel
- LET'S BEGIN graphic
- REST + rest countdown
- GREAT JOB / completion graphic

No subtitles or Voice transcription.
