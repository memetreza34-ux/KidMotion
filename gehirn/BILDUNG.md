# KidMotion — Bildung / Lernen

KidMotion ist NICHT nur ein Sportkanal. Der Kanal darf auch eigenständige Bildungs- und Lernvideos für Kinder enthalten.

## Grundprinzip
Bildung soll visuell, einfach, kindgerecht und mit statischen Bildern funktionieren.

Mögliche Formate:
- ABC / Alphabet lernen
- Buchstaben erkennen
- neue englische Wörter lernen
- Alltagsgegenstände benennen
- Tiere lernen
- Farben lernen
- Zahlen lernen
- Formen lernen
- Körperteile lernen
- Lebensmittel lernen
- Fahrzeuge lernen
- einfache Kategorien und Zuordnungen
- Gegensätze
- links / rechts
- einfache Quiz- und Auswahlvideos

## Beispiel: Wörter lernen
Eine Szene kann ein klar dargestelltes Objekt zeigen und dazu einfachen englischen Lerntext verwenden.

Beispiele:
- `SPOON` — `This is a spoon.`
- `DOG` — `This is a dog.`
- `APPLE` — `This is an apple.`
- `CHAIR` — `This is a chair.`

Die Bilder müssen das jeweilige Objekt eindeutig und groß zeigen.

## Beispiel: ABC
Ein Video kann z. B. heißen:
`LET'S LEARN THE ABC!`

Mögliche Szenen:
- `A — APPLE`
- `B — BALL`
- `C — CAT`
- usw.

Jede Szene zeigt den Buchstaben und ein passendes Bild / Objekt.

## Charakter-Nutzung
Die KidMotion-Hauptfiguren dürfen:
- als Moderator / Guide erscheinen
- auf Objekte zeigen
- Lernkarten präsentieren
- in Intro und Outro erscheinen

Sie müssen aber nicht in jeder einzelnen Lernszene vorhanden sein, wenn das Lernobjekt selbst klarer im Mittelpunkt stehen soll.

## Theme-System
Auch Bildungs-Videos bekommen ein eigenes abgestimmtes Theme-Paket:
- passender Hintergrund
- passende Farben
- passende Kleidung der KidMotion-Figuren, wenn sie vorkommen
- passende Bildwelt
- Cover im selben Thema
- Intro im selben Thema
- alle Szenen visuell konsistent

Beispiele:
- ABC Classroom Theme
- Farm Animals Theme
- Space Vocabulary Theme
- Kitchen Words Theme
- Colors Theme
- Vehicles Theme

## Bild-KI und Remotion
Bei Bildungs-Videos darf die Aufgabenteilung je Format angepasst werden.

Bild-KI kann erzeugen:
- Lernobjekt / Motiv
- thematische Umgebung
- Buchstaben / Wort / kurzen Lerntext direkt im Bild, wenn das Format davon profitiert

Remotion kann erzeugen:
- Intro-Text
- synchronisierte Voice-Cues
- Fortschritt
- Übergänge
- einfache Highlights
- Quiz-Timer, falls ein Quizformat verwendet wird
- Outro

Es gibt KEINE Pflicht, bei Bildungs-Videos einen 20-Sekunden-Sport-Timer zu verwenden. Die 20-Sekunden-Regel gilt für das aktuelle Sport-/Pose-Format, nicht automatisch für Lernvideos.

## Voice
Sprache aktuell: Englisch.

Voice soll sehr einfach sein.
Beispiele:
- `This is a spoon.`
- `Spoon.`
- `Can you say spoon?`
- `A is for apple.`

Keine unnötig langen Erklärungen.

## Cover und Publishing
Auch jedes Bildungs-Video bekommt im Episodenordner:
- `00-cover/cover-prompt.txt`
- `00-cover/cover-text.txt`
- finalen Cover-Asset-Platz
- `05-publishing/publishing.md`

`publishing.md` enthält mindestens:
- YouTube-Titel
- Haupt-Caption
- kurze Caption
- YouTube-Beschreibung
- Hashtags
- Keywords / Search Phrases
- Playlist-Vorschlag

## Harte Regel
KidMotion ist ab jetzt eine breitere Kinder-Marke für:

> MOVE + PLAY + LEARN + EXPLORE

Sport und Bewegung bleiben ein Kernbereich, aber eigenständige Bildungs-/Lernvideos sind ausdrücklich Teil des Kanals.
