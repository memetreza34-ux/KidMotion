# KidMotion — Master Style Prompt

Use this block as the fixed visual-style foundation for every normal KidMotion scene prompt.

```text
High-end stylized 3D animation, polished family-entertainment quality, original character design, soft cinematic lighting, clean shapes, expressive but child-appropriate face, realistic-enough child body proportions for demonstrating fitness and sports poses, slightly stylized larger eyes but NOT oversized head, premium materials, soft skin shading, detailed hair, colorful but tasteful sportswear, clear readable static pose, uncluttered composition, premium YouTube Kids presentation, 16:9 landscape composition, full body visible when required, clean negative space reserved for Remotion overlays.

Use ONLY the one approved KidMotion episode character selected for this video. Preserve exact face identity, age appearance, skin tone, hairstyle, body proportions and overall rendering style. Do not introduce the other KidMotion character or any second visible child/person.

Use the episode-specific themed outfit and world exactly as defined in that episode's REFERENCE_GUIDE.md. The outfit may differ between episodes, but it must stay consistent within the current episode.

For normal VIDEO-SCENE images generate ONLY the character, pose and environment. NO exercise title. NO instruction text. NO cloud or speech bubble. NO subtitles. NO voice captions. NO timer. NO progress bar. NO countdown. NO UI.

Cover / thumbnail Bild 00 is the standard exception and may contain its final thumbnail text.

No existing brand logos. No copyrighted characters. No recognizable franchise resemblance. No photorealistic child. No adult proportions. No exaggerated muscles. No chibi proportions. No malformed hands or limbs.
```

## Usage
Every scene-specific prompt should define:
1. IMAGE NUMBER / scene / final filename
2. one locked episode character
3. exact static pose
4. expression
5. camera framing
6. episode background/world
7. negative-space needs for Remotion UI
8. immediate rename instruction

Then apply this visual foundation without repeating contradictory text-generation rules.
