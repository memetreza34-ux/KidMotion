# KidMotion — Master Style Prompt

Use this block as the fixed visual style foundation for every normal KidMotion scene prompt.

```text
High-end stylized 3D animation, polished family-entertainment quality, original character design, soft cinematic lighting, clean shapes, expressive but child-appropriate faces, realistic-enough child body proportions for demonstrating fitness and sports poses, slightly stylized larger eyes but NOT oversized heads, premium materials, soft skin shading, detailed hair, colorful but tasteful sportswear, clear readable pose, uncluttered composition, premium YouTube Kids presentation, 16:9 composition, space reserved for UI overlays where useful.

Use only the approved KidMotion boy and/or girl design. Preserve face identity, age appearance, skin tone, hairstyle, body proportions and base outfit colors. Do not redesign the characters.

No existing brand logos. No copyrighted characters. No Disney, Pixar, Barbie, Miraculous, Zootopia or other recognizable franchise resemblance. No photorealistic child. No adult proportions. No exaggerated muscles. No chibi proportions. No malformed hands or limbs. No unnecessary text inside normal scene images.
```

## Usage
Every scene-specific prompt should first describe:
1. character
2. exact pose
3. expression
4. camera framing
5. background/world
6. negative-space/UI needs

Then append this full master style block.
