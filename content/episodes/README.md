# KidMotion Episodes

Create one folder per produced video.

Recommended naming:

`KM-001-jungle-adventure/`

Each episode folder should contain:

- `episode.md` — complete production package based on `content/templates/EPISODE_TEMPLATE.md`
- `data.ts` or `data.json` — Remotion-ready timing and asset references
- `images/` — user-generated approved still images
- `audio/` — user-generated voiceover / music / SFX files
- `thumbnail/` — thumbnail assets
- `notes.md` — optional quality-control notes and revisions

Suggested layout:

```text
content/episodes/KM-001-jungle-adventure/
├── episode.md
├── data.json
├── images/
│   ├── scene-01.png
│   ├── scene-02.png
│   └── ...
├── audio/
│   ├── intro.wav
│   ├── exercise-01.wav
│   └── outro.wav
├── thumbnail/
│   └── thumbnail.png
└── notes.md
```

The user creates image and audio assets externally from the prompts and voice scripts generated by the KidMotion content workflow. Remotion is responsible for final assembly and rendering.
