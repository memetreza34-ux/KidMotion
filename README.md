# KidMotion

KidMotion is an original English-language kids movement and fitness channel concept built around two recurring 3D animated main characters: one boy and one girl.

The channel is broader than yoga. Planned content can include kids fitness, yoga, stretching, balance, cardio, sports, movement games, themed adventures and challenges.

## Current status

We are currently defining and locking the two main characters before building the production pipeline.

## Core rule

Do not redesign the two main characters without an explicit decision. Their face, hair, body proportions, base outfit colors and overall visual identity should stay consistent across videos.
