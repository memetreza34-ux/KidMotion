# KIDMOTION LEARNING ENGINE

KidMotion Learning uses a teaching engine rather than a single visual formula.

## Planning order

1. **AGE BAND**
   - `3-4` Preschool
   - `5-8` Young learners
   - `9-12` Older kids
2. **ONE PRIMARY LEARNING OBJECTIVE**
3. **LEARNING MODE**
4. success criteria
5. facts + source notes
6. vocabulary + misconceptions
7. scene roles
8. practice/reveal
9. real-world application
10. recap
11. narration
12. visual prompts

Do not start with images.

## Learning modes

### CONCEPT_STORY
For abstract concepts that can become visible through a small story or transformation.

### QUESTION_EXPLAINER
For a clear why/how question such as “Why do volcanoes erupt?”

### SONG_MEMORY
For stable sequences, vocabulary, letter sounds, names or facts that benefit from repetition.

### PRACTICE_REVEAL
For recognition, counting, phonics, matching and quiz-style learning.

### VISUAL_COMPARE
For categories, opposites, scale, similarities and differences.

### MINI_DOCUMENTARY
For science, animals, geography, history, machines and real-world systems.

## Scene roles

Typical learning scenes use:
`HOOK → TEACH → EXAMPLE → PRACTICE → REVEAL → APPLY → RECAP`

Modes may add roles like CONTEXT, COMPARE, REPEAT or CLOSING_QUESTION.

A scene is not allowed just because it looks good. Every scene needs a teaching job.

## Active recall

At least one PRACTICE → REVEAL pair is required.

Practice:
- asks the child to predict, choose, count, identify or match
- gives thinking time
- does not show the answer early

Reveal:
- gives the correct answer
- explains why

## Multi-channel learning

Important ideas should normally use at least:
- voice
- visual

Text is optional and should be used when it improves recognition or memory.

Examples:

`3` + three apples + narrator says “three”.

`Mars` + the planet’s visual features + narrator says “Mars”; a label can be added if useful.

## Characters

Default for pure learning: `none`.

A child or mascot is allowed only if it improves explanation, story or interaction. If used, the plan must state why.

## Quality gate

A production-ready learning episode must prove:
- exactly one primary objective
- clear success criteria
- age-appropriate language
- facts have source notes
- planned misconception handling
- at least one active practice/reveal moment
- every scene has a role and learning point
- application when appropriate
- recap
- no workout-only structures
- no decorative character insertion
- no filler beauty shots
