# KM-002 — Bilder

Generate with Google Flow from `bild-prompts.md`.

## Workflow
`PROMPT LESEN → GENAU EIN BILD ERZEUGEN → EIN-BILD-KLARHEIT PRÜFEN → SOFORT UMBENENNEN → ERST DANN NÄCHSTES BILD`

Required files:
- Bild 00.png — Cover only
- Bild 01.png — Intro / primary girl reference
- Bild 02.png — Safety
- Bild 03.png — Let's Begin
- Bild 04.png–Bild 15.png — 12 exercise poses
- Bild 16.png — Outro

## Hard acceptance rule for exercises
Do not accept an exercise image unless a child can understand the body position from the still image itself.

Reject/regenerate if:
- pose needs movement to make sense
- limbs overlap or disappear
- key joints are hidden
- feet/hands are cropped when important
- silhouette is unclear
- anatomy is wrong
- second person appears
- character identity drifts
- title/instruction is duplicated or misspelled

If the same pose is still unclear after two good Google Flow attempts, replace the pose rather than forcing it.
