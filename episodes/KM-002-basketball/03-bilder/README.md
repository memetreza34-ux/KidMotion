# KM-002 — Bilder

Generate with Google Flow from `bild-prompts.md`.

## Workflow
`PROMPT LESEN → GENAU EIN BILD ERZEUGEN → EIN-BILD-KLARHEIT PRÜFEN → TEXT/UI PRÜFEN → BALLANZAHL PRÜFEN → SOFORT UMBENENNEN → ERST DANN NÄCHSTES BILD`

Required files:
- Bild 00.png — Cover only
- Bild 01.png — Intro / PRIMARY girl reference
- Bild 02.png — Safety
- Bild 03.png — LET'S BEGIN
- Bild 04.png–Bild 15.png — 12 exercise poses
- Bild 16.png — clean Outro

## Reference system
- `Bild 01` = PRIMARY character/world reference for every later image.
- `Bild 04` = SECONDARY exercise UI/layout reference for `Bild 05`–`Bild 15` after Bild 04 is approved.

## Exercise acceptance
Reject/regenerate if:
- pose needs movement to make sense
- limbs overlap/disappear
- key joints hidden
- feet/hands cropped
- silhouette unclear
- anatomy wrong
- second person appears
- character drifts
- title/instruction misspelled or duplicated
- title/cloud style differs strongly from Bild 04
- thought-bubble dots appear
- title touches left/bottom edge
- cloud touches top/right edge
- top-left timer safe zone is occupied
- lower progress safe zone is occupied
- wrong number of basketballs appears

## Ball rule
- scenes marked no-ball = ZERO basketballs anywhere
- ball scenes = EXACTLY ONE basketball
- no loose/background duplicate balls

## Text-free images
`Bild 01`, `Bild 02`, `Bild 03`, `Bild 16` must contain ZERO Google Flow text.

Especially reject `Bild 16` if it contains `GREAT JOB`, `WORKOUT COMPLETE` or any decorative completion words. Remotion owns the only Outro text.

## Important render lesson
Exercise/rest images will no longer be zoomed by Remotion. Keep all generated title/cloud elements safely inside frame anyway.
