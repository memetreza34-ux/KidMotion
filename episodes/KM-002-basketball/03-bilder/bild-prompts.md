# KM-002 — Google Flow Image Prompts

## HARD RULES — READ BEFORE GENERATING
- Exactly ONE recurring character for the complete episode: the approved KidMotion GIRL.
- `Bild 01.png` is the PRIMARY CHARACTER reference for `Bild 02.png` through `Bild 16.png`.
- Same face, ponytail, age appearance, skin tone, proportions, purple/aqua basketball outfit, shoes, gym and premium 3D style throughout.
- Jersey may show only the simple number `12`; no fake team names, logos, sponsors or brand marks.
- No second child, coach, spectator or background person.
- 16:9 landscape, 1920x1080 target.
- Generate exactly ONE image at a time, inspect it, rename it immediately, then continue.

## EIN-BILD-KLARHEITSTEST
Every exercise must be understandable from one still image before reading the text.

Accept only if:
1. full body is visible from head to shoes
2. arms and legs are clearly separated
3. important joints are visible
4. silhouette is obvious
5. pose has one static end position
6. no movement direction or animation is needed
7. anatomy is natural and child-safe
8. no limb is hidden behind another limb or prop in a confusing way

If a pose is still unclear after two serious generations, REPLACE THE POSE instead of adding more explanation.

## BALL COUNT — HARD RULE
- If a prompt says `NO BALL`, there must be ZERO basketballs anywhere in the image, including the floor and background.
- If a prompt says `ONE BALL`, there must be EXACTLY ONE plain orange basketball and it must be used by the girl as described.
- Never generate spare balls, loose balls on the court, duplicate balls or background basketballs.

## EXERCISE TEXT — HARD RULE
For `Bild 04.png` through `Bild 15.png`, Google Flow itself creates exactly:
- ONE exercise title at BOTTOM-LEFT
- ONE short instruction at TOP-RIGHT inside the KidMotion white cloud

Remotion will NOT recreate these texts.

### Locked title style
- bold white rounded athletic lettering
- thick dark-navy outline + small soft shadow
- same font feel, size and spacing on every exercise
- left margin about 80–100 px
- title must sit clearly ABOVE the bottom progress safe zone
- never crop any letter at the left or bottom edge

### Locked instruction-cloud style
- ONE clean rounded white cloud / soft rounded bubble
- turquoise outline
- dark-navy bold rounded text
- NO thought-bubble dots
- NO comic tail made from multiple circles
- same shape, outline, font and approximate size on every exercise
- right margin at least 80 px
- never touch the top or right frame edge

### UI REFERENCE WORKFLOW
1. Generate and approve `Bild 04.png` first.
2. Once approved, use `Bild 04.png` as the SECONDARY UI/LAYOUT reference for `Bild 05.png` through `Bild 15.png`.
3. `Bild 01.png` remains the PRIMARY character/world reference.
4. Copy only the title/cloud visual system from `Bild 04`; do NOT copy its pose or wording.

## SAFE ZONES — HARD RULE
- TOP-LEFT: keep a clear 220x220 px area for the Remotion timer.
- BOTTOM EDGE: keep the lowest ~90 px visually clear for the Remotion progress bar.
- Exercise title must stay above that bottom safe zone.
- Instruction cloud must stay top-right and must never overlap the character.
- The girl must stay fully inside frame with visible shoes and hands.

Do NOT generate into exercise images:
- subtitles
- transcript bars
- timer
- progress bar
- REST UI
- duplicate title
- duplicate instruction

For `Bild 01`, `Bild 02`, `Bild 03` and `Bild 16`: generate ZERO text of any kind. Remotion owns those graphics.
