# KM-002 — Antigravity Production Instructions

Read `GEHIRN.md` first. Then read this episode's `README.md`, `01-skript/voice-text.md`, `03-bilder/bild-prompts.md` and `04-data/data.json`.

## Do not activate or render until final assets exist
Required final assets:
- `Bild 00.png` through `Bild 16.png`
- `Voice 01.mp3` for Intro
- optional licensed `bg-music.mp3`

## Hard visual rule
Every exercise is a STATIC HOLD and must work from one still image.

Reject an exercise image if:
- movement is needed to understand it
- limbs overlap or disappear
- silhouette is unclear
- anatomy is wrong
- pose needs a long explanation
- second person appears
- girl identity/outfit/world changes

After two failed Google Flow attempts for one pose, replace the pose rather than trying to rescue it with more text.

## Character
Use exactly the same approved KidMotion girl for every visible video scene.
`Bild 01.png` is the primary continuity reference for all later images.

## Audio
Only Intro contains spoken Voice:
`Voice 01.mp3`

After Intro the video is silent except for low background music.
Never add exercise announcements, instructions, motivational filler or spoken countdowns.
Never create subtitles or captions.

## Google Flow / Remotion split
For exercise images, Google Flow already creates:
- exercise name bottom-left
- short instruction cloud top-right

Remotion MUST NOT duplicate them.

Remotion adds only:
- circular 20-second timer top-left
- progress bar
- exact scene timing
