# KidMotion — Audio Drop / ACTIVE EPISODE STAGING

This folder is the Remotion audio staging area for ONE active episode at a time.

# HARD RULE — ONLY INTRO VOICE
Current KidMotion standard uses spoken Voice only in Scene 01 Intro.

Normally the only required audio file is:
- `Voice 01.mp3` — short Intro introduction

Do NOT create or use Voice files for:
- Safety
- LET'S BEGIN
- Exercises
- Rest
- Outro

For KM-001, `Voice 02.mp3` through `Voice 16.mp3` are not part of the current production structure.
If old files with those names exist, do not mount or use them.

## Intro target
Target roughly 6–8 seconds.

KM-001 Intro text:
`Hi, KidMotion friends! Twelve football poses, twenty seconds each. Find some space and follow along!`

After Intro ends, the whole video remains silent.

## Never mix episodes
Before loading a different episode:
1. remove/archive the previous active audio
2. place only the current episode Intro file here if it exists
3. verify filename against `ALL_VOICE_TEXTS.md`

## Video duration
Audio never controls video duration.
A 5+ minute workout may contain only about 6–8 seconds of spoken audio.

## No subtitles
Never convert the Intro Voice into automatic subtitles, word-for-word captions, transcript bars or karaoke text.
