# KM-001 — Google Flow Image Prompts

## HIGHEST RULE — ONE STILL IMAGE MUST EXPLAIN THE POSE
Every exercise must be understandable from exactly ONE static image.

Before generating any exercise, ask:
> Could a child copy this body position from this one picture without needing motion, a before/after frame, or a long explanation?

If the answer is not clearly YES, replace the pose.

### Required for every exercise image
- exact same approved KM-001 boy
- same face, hair, age appearance, proportions, royal-blue/lime football outfit and football pitch
- exactly one visible person
- full body visible
- important joints visible
- arms and legs clearly separated from each other and from the torso
- clear silhouette
- obvious static end-position
- front or clean three-quarter camera angle
- no movement direction needed to understand the pose
- no hidden key body part

### Forbidden pose types
- kicks, jumps, running phases or ball actions that need motion to understand
- before/after actions
- repetitive exercises
- subtle micro-positions where the main difference is hard to see in a full-body still
- complex crossed/overlapping limbs
- poses that only make sense because of the written instruction

If Google Flow cannot create the pose clearly after two serious attempts, REPLACE THE POSE instead of adding more text.

## CHARACTER CONTINUITY
- `Bild 01.png` is the PRIMARY visual reference for `Bild 02.png` through `Bild 16.png`.
- No girl, second child, coach, spectator or background person.
- 16:9 landscape, 1920×1080 target.
- Generate exactly ONE image, rename immediately, then continue.

## EXERCISE TEXT RESPONSIBILITY
For `Bild 04.png` through `Bild 15.png`, Google Flow itself creates:
- exercise name at BOTTOM-LEFT
- short instruction at TOP-RIGHT inside the white KidMotion cloud/info bubble

The text CONFIRMS the already-clear pose. It must never be needed to rescue an unclear image.

Text style:
- title: bold white athletic lettering, dark navy outline/shadow
- instruction: white playful cloud, turquoise outline, dark navy rounded text, max 2–3 lines
- keep TOP-LEFT clear for Remotion timer
- keep bottom edge clear for Remotion progress bar

Never generate subtitles, transcript bars, timer or progress bar into exercise images.
